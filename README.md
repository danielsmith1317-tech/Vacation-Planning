# Vacation Planning

Permanent multi-trip vacation hub for the Smith family.

## Trip-page standard

Every trip page should carry forward the same core planning features used in the Paris & London planner where relevant:

- Overview and trip status
- Flights / trains / transportation
- Hotels or rentals
- Itinerary / things to do
- Map links and embedded map context
- Confirmed / planned booking links
- Budget / booking notes where applicable
- Live weather that loads automatically when the page opens
  - Future trips: current conditions + short-range forecast are planning context only until the trip enters forecast range
  - Archived trips: current conditions are reference weather, not historical trip weather

Use the existing authorized Google Maps / Weather setup when available and keep private booking-access details off the public site.
